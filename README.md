# Workflow Studio 1.9

منصة محلية لبناء سير عمل مرئي للمحتوى والأنيميشن.

## المزايا
- واجهة عقد مرئية قابلة للسحب.
- كتابة السكريبت وإدخال النص.
- تفريغ ملفات الصوت العربية عبر Whisper.
- تحسين النصوص باستخدام OpenAI.
- تقسيم السكريبت إلى مشاهد مع وصف بصري ومدة وتعليق صوتي.
- استخراج دليل ثابت للشخصيات (الملامح والملابس والألوان) وتكراره في أوصاف الصور لتحسين الاتساق.
- رفع صورة مرجعية للشخصية واستخدامها مع واجهة تحرير الصور عند توليد المشاهد.
- توليد صورة لكل مشهد باستخدام Images API.
- تجميع الصور في فيديو WebM بحركة تقريب/تحريك بسيطة وتعليقات مكتوبة.
- توليد تعليق صوتي عربي لكل مشهد ومزامنته داخل الفيديو.
- خط زمني للمشاهد لتعديل التعليق الصوتي والمدة وحركة الكاميرا وترتيب المشاهد أو حذفها.
- حفظ محلي للمشاهد والعقد وتصدير المشروع بصيغة JSON.

## المتطلبات
- Node.js 18 أو أحدث.
- مفتاح OpenAI API مع صلاحية الوصول إلى النماذج المستخدمة.

## التشغيل
1. فك ضغط المشروع.
2. افتح مجلد المشروع في Terminal.
3. نفّذ `npm install`.
4. انسخ `.env.example` إلى `.env`.
5. ضع مفتاحك في `OPENAI_API_KEY`.
6. نفّذ `npm start`.
7. افتح `http://localhost:3000`.

## تنبيه
- المفتاح محفوظ في الخادم داخل `.env` ولا يوضع في كود المتصفح.
- التفريغ وتوليد النصوص والصور يستهلك رصيد API وقد تختلف إتاحته حسب حسابك.
- هذه النسخة تولّد مخطط مشاهد وصوراً ثابتة؛ لا تقوم بتجميع فيديو أنيميشن متحرك تلقائياً.
- اختبر المخرجات وراجعها قبل استخدامها أو نشرها.


## إنشاء الفيديو
بعد تشغيل عقدة تقسيم المشاهد، اضغط زر **إنشاء فيديو**. سيولّد التطبيق صورة لكل مشهد ثم يجمعها في ملف WebM داخل المتصفح. قد تحتاج وقتاً ورصيد API حسب عدد المشاهد. الميزة لا تنتج تحريك شخصيات frame-by-frame ولا تضيف تعليقاً صوتياً تلقائياً.


## التعليق الصوتي
عند إنشاء الفيديو، يحوّل التطبيق نص كل مشهد إلى صوت عبر واجهة OpenAI Text-to-Speech، ثم يدمج الصوت مع مسار الفيديو داخل المتصفح. قد تختلف جودة نطق العربية والصوت حسب النموذج والصوت المتاحين. ميزة إنشاء الفيديو تتطلب اتصالاً بالإنترنت ومفتاح API ورصيداً كافياً.


## اتساق الشخصيات
بعد تقسيم السكريبت، يعرض التطبيق دليل الشخصيات المستخرج من النص. يُستخدم هذا الدليل تلقائياً في أوصاف الصور ومشاهد الفيديو للمساعدة في ثبات التصميم. هذا تحسين نصّي للاتساق وليس ضماناً لتطابق الصورة 100%؛ التطابق البصري الأقوى يحتاج استخدام صور مرجعية للشخصيات أو أدوات تحرير صور تدعم المراجع.


## الصور المرجعية للشخصيات
من اللوحة اليمنى، ارفع صورة PNG أو JPEG أو WebP للشخصية. عند توليد الصور أو الفيديو، يستخدم الخادم مسار Images Edits مع الصورة المرجعية والنص الوصفي. هذه الميزة تساعد على تقليل اختلاف شكل الشخصية، لكنها لا تضمن تطابقاً كاملاً في كل إطار. يجب أن تكون لديك صلاحية Images API، وقد تترتب تكلفة على كل صورة يتم توليدها.


## تحرير خط المشاهد الزمني (الإصدار 1.9)
بعد تقسيم السكريبت، يظهر محرر لكل مشهد. يمكنك تعديل نص التعليق الصوتي، وضبط المدة من 3 إلى 30 ثانية، واختيار حركة كاميرا (تقريب أو ابتعاد أو تحريك جانبي أو ثابت)، وإعادة ترتيب المشاهد أو حذفها. إعدادات المشاهد تُحفظ مع المشروع محلياً وتدخل في ملف JSON المُصدّر. عند إنشاء الفيديو تُستخدم المدة وحركة الكاميرا المختارتان؛ وإذا كان التعليق الصوتي أطول من المدة المحددة، يمتد المشهد تلقائياً حتى ينتهي الصوت.

**حدود النسخة:** الفيديو الناتج WebM من صور المشاهد مع حركة كاميرا رقمية وتعليق صوتي. لا تتضمن النسخة تحريكاً هيكلياً للشخصيات أو مزامنة شفاه دقيقة، ولا تضمن تطابق الشخصية في كل صورة.


## إضافات الإصدار 1.10
- توليد صورة لكل مشهد بشكل منفصل ومعاينتها داخل الخط الزمني.
- إعادة توليد صورة مشهد محدد دون إعادة بقية الصور.
- الاحتفاظ بالصور المولدة في جلسة المتصفح وإعادة استخدامها عند إنشاء الفيديو لتجنب توليدها مرتين في نفس الجلسة.
- زر لتوليد صور جميع المشاهد بالتتابع.

ملاحظة: توليد الصور يستهلك رصيد API. الصور المحفوظة مؤقتًا في الذاكرة لا تُضمن بعد إغلاق/تحديث الصفحة.


## Version 1.11 additions
- Import a previously exported workflow project JSON file.
- Export scene voiceover text as an SRT subtitle file using each scene's configured duration.
- Automatically writes a recovery copy to local browser storage when the page is closed.

Note: SRT timing is estimated from configured scene durations. If generated speech is longer than a scene duration, adjust the duration before exporting subtitles for closer alignment.
